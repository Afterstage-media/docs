# Medio Under — POC

> Este repositorio es una referencia visual y de contenido histórico. La superficie pública canónica es `frontend/` (React/Vite); no debe desplegarse este HTML en paralelo con la aplicación activa.

Prototipo navegable para un medio/comunidad de cultura under: historias, agenda, oportunidades freelance, descuentos para producir y experiencias de fans.

## Cómo verlo

Abrí [`index.html`](./index.html) directamente en el navegador. No requiere build ni dependencias.

## Pantallas mockeadas

- Inicio editorial y tablero de oportunidades.
- Comunidad de noteros, fotógrafos, bandas y cronistas.
- Portfolio fotográfico y videográfico por perfil.
- Columnas de cronistas y periodistas.
- Perfil de banda con agenda propia.
- Agenda de shows con filtros.
- Publicar una oportunidad o historia.
